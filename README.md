### Introduction

This is a lightweight benchmarking system that I built for myself to compare results and calculate speed-up when parallelizing AMDAT. Frankly, I realize that currently there is no kernel for future developers to facilitate their software development workflow. This system might not be extremely full-fledge due to how minimalistic it is at the moment, but I will try to improve it while developing AMDAT. In short, I think it can be beneficial to publish this to my Github.
